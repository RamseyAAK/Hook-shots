# CS35_Project
A game-ish project made for CS35

### NOTE:
  A Gamepad is currently required for player input.

## Contributors 
- Ramsey Antrim-Kerr: RamseyAAK@gmail.com

## The Game
A 2D game where you to control a character whose only method of movement is thier two hook-shots

### Motivation
I wanted to make a game that uses continuous inputs for the main player movement mechanic 

### Gameplay loop
Currently undecided. I have vague ideas of a puzzle room game where mechanics are added one at a time, or an exploration game where player capabilities are gradually gained.
